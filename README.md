# Trends Hair Studio — Smart Luxury Salon Web App ✂️

A mobile-first, luxury appointment booking and queue management system designed for **Trends Hair Studio**, Satellite, Ahmedabad.

## ✨ Core Highlights & Features

1. **Smart Dynamic Duration Engine**
   - Calculates the exact cumulative duration (e.g. 45m cut + 30m beard = 75m).
   - Only shows continuous available slots, eliminating double bookings.

2. **Live Chair Wait Meter**
   - Shows real-time chair availability (e.g. *"Next opening at 11:45 AM"*).
   - Solves the constant *"Are you free right now?"* phone call dilemma.

3. **Hands-Free Stylist Voice Announcer**
   - Web Audio luxury concierge chime + Web Speech text-to-speech announcement.
   - Stylist terminal announces new bookings and auto-flow completion out loud so barbers never need to touch their phones with wet/product-coated hands.

4. **1990s Bollywood Retro Vinyl Lounge**
   - Vintage 12" rotating vinyl turntable with animated physical tonearm stylus needle.
   - Curated classic 90s Bollywood hits (Kumar Sanu, Alka Yagnik, Udit Narayan, R.D. Burman).
   - Persistent mini-player snackbar across all pages.

5. **Multi-Theme Luxury Palette Engine**
   - **Warm Alabaster & Noir** (*Lumée & The Reset World*)
   - **Royal Emerald & Gold** (*Mayfair / Vogue Haute Coiffure*)
   - **Cashmere Sand & Espresso** (*Aesop & Scandinavian Minimalist*)
   - **Obsidian Noir & Champagne** (*Tom Ford Haute Dark*)

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4 + Custom Luxury Glassmorphism & Animations
- **Icons:** Lucide React
- **Audio & Voice:** Native Web Audio API (`AudioContext`), Web Speech API (`SpeechSynthesis`), HTML5 Audio
- **Sync:** Cross-tab `BroadcastChannel`

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
